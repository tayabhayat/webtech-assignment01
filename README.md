
# Personal Resume Website

## About the Project
This project is a personal resume website created using HTML and CSS as part of my Web Technologies assignment at PUCIT, Lahore.

The website showcases my educational background, professional experience, technical skills, and portfolio.

## Features
- Professional summary
- Work history and freelance experience
- Technical and creative skills
- Educational background
- Portfolio links to GitHub, LinkedIn, and Google Drive

## Technologies Used
- HTML5
- CSS3
